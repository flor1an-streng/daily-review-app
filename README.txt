DAILY REVIEW – ANDROID PWA (kostenlose erste Version)

ENTHALTEN
- Tagesbewertungen (1–5) für sechs Kategorien
- Drei Reflexionsfelder
- Speichern im lokalen Browserspeicher
- Monatskalender mit markierten Einträgen
- Statistiken, Kategorie-Durchschnitte und Verlauf
- Gewichtbare Bewertungskategorien (Faktor 1–3)
- Wochenanalyse der letzten sieben Tage
- Eigene Ziele mit Erledigt-Status
- JSON-Export und -Import für Einträge, Einstellungen und Ziele
- Offline-Grundfunktion nach dem ersten Laden

AUF ANDROID TESTEN
1. ZIP entpacken.
2. Die Dateien müssen über eine HTTPS-Adresse bereitgestellt werden, damit Installation und Offline-Funktion als PWA funktionieren.
3. Kostenlos möglich: GitHub-Konto erstellen, ein neues öffentliches Repository anlegen und die Dateien hochladen.
4. Im Repository unter Settings > Pages die Veröffentlichung über den main-Branch und /(root) aktivieren.
5. Die angezeigte GitHub-Pages-Adresse in Chrome auf dem Android-Handy öffnen.
6. Chrome-Menü (⋮) > „App installieren“ oder „Zum Startbildschirm hinzufügen“.

WICHTIG
- Die Daten liegen nur lokal in genau diesem Browser auf diesem Gerät.
- Browserdaten löschen kann Einträge entfernen. Deshalb regelmäßig über Statistiken > Exportieren sichern.
- Diese erste Version hat noch keine Cloud-Synchronisierung, Benutzerkonten oder automatischen Push-Erinnerungen.
- Für private Nutzung kann das GitHub-Repository öffentlich sein, ohne dass deine Einträge öffentlich werden: Es enthält nur den App-Code. Schreibe keine persönlichen Tagebucheinträge in die Code-Dateien.

VERSION 2.0: Die App aktualisiert sich nach erneutem Laden der veröffentlichten Website. Bestehende Tagesbewertungen bleiben im Browser gespeichert; neue Einstellungen und Ziele werden separat lokal ergänzt.
